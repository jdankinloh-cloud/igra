# 🎉 Действие или Правда — Мультяшная вечеринка

Детская игра-приложение для компании 5–7 лет. Один HTML-файл, работает **офлайн**, без внешних библиотек — просто откройте `index.html` на телефоне или компьютере.

## 🎮 7 режимов

| Режим | Что это |
|---|---|
| 🤸 **Действие** | 134 физических задания: прыжки, приседания, отжимания — без повторов, пока пул не кончится |
| 💬 **Правда** | Викторина про мультики с ответами: Черепашки Ниндзя, Губка Боб, Маша и Медведь, Свинка Пеппа, Ми-ми-мишки, Барбоскины, Леди Баг — 141 вопрос |
| 🎯 **Случайное имя** | Рулетка или кейс в стиле CS2 выбирают, кто отвечает на вопрос |
| 🏁 **Гонка** | Настольная игра с кубиками на 2–4 игроков: серпантин 6×5, бонусы ⭐, ловушки 💥, 3D-кубики |
| 🎁 **Сундуки** | 2–5 игроков, у каждого 5 сундуков: конфеты, звёзды, алмазы, бомбы, подарки, молнии |
| 🧠 **Повторяшка** | Игра на память в духе «Саймона»: зверята светятся — повтори последовательность. Рекорд сохраняется |
| 🔮 **Гороскоп** | Весёлый «прогноз дня» по имени: предсказание, сладость дня, зверь дня, суперсила и цвет дня |

## ⚙️ Особенности

- 16 имён игроков; ненужные можно выключить в **⚙️ Настройках** — выбор сохраняется на устройстве (localStorage)
- Вибрация, звуки (WebAudio), конфетти, анимации — всё на чистом CSS/JS
- Оптимизировано под телефон от 320px: safe-area, крупные кнопки, никаких внешних ресурсов

## 🚀 Как играть

Откройте `index.html` в любом браузере. Всё.

index.html   — вся игра (HTML + CSS + JS в одном файле)
